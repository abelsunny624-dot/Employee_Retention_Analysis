Project Overview:

Employee attrition is a critical challenge for organizations, leading to increased recruitment costs, productivity loss, and knowledge gaps. This project analyzes HR data to identify key drivers of employee turnover and provides actionable insights through interactive dashboards and predictive modeling.

--------------------------------------------------------------------------------------------------------
Objectives:

Understand attrition patterns across departments, compensation levels, and tenure.

Build interactive dashboards for HR teams to monitor retention KPIs.

Predict employee attrition risk using machine learning models.

Provide recommendations to reduce turnover and improve workforce stability.

_______________________________________________________________________________________________________
Tech Stack:

Languages: Python (Pandas, NumPy, Scikit-learn)

Visualization: Streamlit, Matplotlib, Seaborn

Data Tools: SQL, Excel

Dashboarding: Power BI (optional extension)

______________________________________________________________________________________________________
Key Features:

Data Cleaning & Validation: Ensures accuracy across employee records.

Interactive Dashboard: Attrition metrics by department, tenure, and demographics.

Predictive Modeling: Logistic regression to estimate attrition risk.

Business KPIs:

Attrition Rate (%)

Average Tenure
